# HXD1C 确认行车凭证虚拟实训

独立的课堂 H5 项目，用于 HXD1C 货物列车在株洲站 1 道向七斗冲方向发车前的“确认行车凭证”教学和考评。

## 固定教学条件

- 列车：2026 次货物列车，HXD1C 电力机车。
- 地点：京广线株洲站 1 道，七斗冲方向。
- 终点：越过地面出站信号机后稳定运行 300 m。
- 页面仅保留本次成绩，不记录学生身份或历史结果。

## 场景

1. 正常凭出站信号发车；
2. 天气恶劣、难以辨认地面信号；
3. 出站信号机故障，凭绿色许可证发车；
4. 停止基本闭塞法，改按电话闭塞法、凭路票发车。

车站侧联控仅使用项目 `assets/audio/radio/` 中的三段录音；学生通过屏幕文字完成应答和核对。天气恶劣场景中，地面信号与机车信号不一致会触发立即停车。

## 运行与发布

这是无构建依赖的静态网站。可直接用任意静态 HTTP 服务启动；部署到 GitHub Pages 时，将仓库根目录发布为 Pages 根目录。

游戏包中的株洲站实景资源仅用于本项目的课堂场景转换，原始游戏目录未被修改。
