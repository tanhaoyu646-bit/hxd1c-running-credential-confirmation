# HXD1C 确认行车凭证虚拟实训

独立的课堂 H5 项目，用于 HXD1C 货物列车在株洲站 1 道向七斗冲方向发车前的“确认行车凭证”教学和考评。

本版本将原发车作业内宜线（内江站—内江南方向）作为三维课堂载体；行车凭证内容、三段车站联控录音和评分任务仍按株洲站课堂数据执行，不将三维载体视为株洲站实景复原。

## 固定教学条件

- 列车：2026 次货物列车，HXD1C 电力机车。
- 地点：京广线株洲站 1 道，七斗冲方向。
- 终点：越过地面出站信号机后稳定运行 300 m。
- 页面仅保留本次成绩，不记录学生身份或历史结果。

## 场景

1. 正常凭出站信号发车；
2. 天气恶劣、难以辨认地面信号；
3. 出站信号机故障，凭绿色许可证发车；
4. 停止基本闭塞法，改按电话闭塞法、凭路票发车。

车站侧联控仅使用项目 `assets/audio/radio/` 中的三段录音；学生在驾驶台 CIR 中呼叫／接收来话，并通过规范复诵选项完成第一版应答，后续可在同一状态接口接入语音识别。天气恶劣场景中，地面信号与机车信号不一致会触发立即停车。

教学／考评窗口只负责模式和场景选择。地面信号、机车信号、LKJ、CIR、列尾风压和送交司机的纸质行车凭证均从驾驶台对应对象直接操作。

LKJ 显示比例与状态栏以原实训系统 `模拟演练/MainImg/LKJ/LKJ.jpg` 为画面基准；驾驶台机械风压表、绿色双针风压表和速度表使用原 HXD1C CABVIEW 指针资源。CIR 热区位于驾驶台最右侧竖排红色按钮区域，不覆盖左侧风压表。

绿色许可证和电话闭塞路票场景在凭证核对后还必须完成LKJ非正常行车解锁；正常和天气场景不要求该解锁。
